## [0.1.0] - 2026-09-14

### Added

- Google TV and Android TV player with HTTP/HLS video playback in a floating overlay.
- Six window positions, adjustable size and independent volume.
- HTTP control server for the existing APiP Remote, with manual server entry, stream selection, fullscreen, PiP and Close App.
- TV controls for starting and stopping the player and granting overlay permission.
- PowerShell build and installation scripts, APK checksum generation and Downloader installation instructions.
- Protocol documentation based on tests with the original Android APiP Remote.
